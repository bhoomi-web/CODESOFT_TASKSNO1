Python Pandas Jupyter Status

📌 Project Overview
This project demonstrates an end-to-end Data Cleaning, Preprocessing and Exploratory Data Analysis (EDA) workflow using a messy clinic appointment dataset.

The raw dataset contains inconsistent categorical values, mixed date formats, missing values and billing values that require cleaning before analysis.

🎯 Objective
Transform the raw clinic appointment data into a structured, consistent and analysis-ready dataset using Python, Pandas, NumPy, Matplotlib and Seaborn.

🧹 Data Cleaning Performed
1. Gender Standardization
Different representations are standardized:

Male, male, M, 1 → Male
Female, female, F, 0 → Female
2. Follow-up Standardization
Values such as:

Y, 1 → Yes
N, 0 → No
3. Date Cleaning
The notebook converts mixed date formats into proper datetime values using Pandas.

Columns processed include:

appointment_date
booking_date
Invalid date values are handled using errors="coerce".

4. Billing Amount Cleaning
Currency symbols/text are removed and billing amounts are converted into numeric values.

The notebook also maintains a currency field.

5. Missing Value Treatment
Missing values are inspected and treated for the analysis.

6. Feature Engineering
The project creates useful features such as:

appointment_month
booking_to_appointment_days
📊 Exploratory Data Analysis
